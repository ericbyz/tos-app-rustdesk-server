🛰️ RustDesk Server自建远控中继 · hbbs + hbbr

服务状态

服务作用端口
hbbs(ID/信令)设备注册、打洞与 ID 分配TCP 21114-21116, 21118 / UDP 21116
hbbr(中继)远控流量中继TCP 21117, 21119

两个服务由系统管理(开机自启)。密钥与数据库保存在 /var/lib/rustdesk-server。

客户端配置(RustDesk 桌面/手机端)

  1. 打开 RustDesk 客户端 → ID 服务器 填本机地址:__NAS_ADDR__
  2. Key 填本机公钥(见下方);中继服务器可留空(默认同 ID 服务器)

公钥文件:/var/lib/rustdesk-server/id_ed25519.pub。在 TOS 终端执行 cat /var/lib/rustdesk-server/id_ed25519.pub 查看。

常用操作(TOS 终端)

systemctl status hbbs hbbr — 查看服务状态

systemctl restart hbbs hbbr — 重启服务

cat /var/lib/rustdesk-server/id_ed25519.pub — 查看客户端所需 Key

跨公网使用时,请在上表端口的路由器上做端口映射,并把客户端的 ID 服务器填成本机公网/DDNS 地址。
